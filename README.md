# Hi, I'm Firtina

I build AI-powered creative tools, WebGL/XR experiences, games, and TypeScript systems that run at the edge.

I'm a Product Engineer at [Gizmo](https://gizmo.ai), and I use [Lunix Tech](https://github.com/Lunix-AI) as a home for side projects, experiments, and open-source work.

## What I'm Into

I like building tools that make complicated things feel playful: editors, agents, browser extensions, game-dev utilities, realtime systems, and small frameworks that remove friction from shipping.

Lately I have been spending a lot of time with Cloudflare Workers, Durable Objects, React Router, WebSockets, multimodal AI, and developer tooling. Before that, a lot of my work lived around Unity, games, WebGL, three.js, and interactive 3D experiences.
