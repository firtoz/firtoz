# Hi, I'm Firtina

I build AI-powered creative tools, WebGL/XR experiences, games, and TypeScript systems that run at the edge.

I'm a Product Engineer at [Gizmo](https://gizmo.ai), and I use [Lunix Tech](https://github.com/Lunix-AI) as a home for side projects, experiments, and open-source work.

## Selected Projects

- [Cloudflare Multi-Worker Starter Kit](https://github.com/firtoz/cf-multiworker-starter-kit) - a production-minded starter for Cloudflare Workers, Durable Objects, React Router, D1, Drizzle, Hono, Turborepo, and Alchemy.
- [fullstack-toolkit](https://github.com/firtoz/fullstack-toolkit) - typed building blocks for full-stack TypeScript apps across React Router, Workers, Durable Objects, Hono, Drizzle, WebSockets, and shared utilities.
- [Tab Canopy](https://github.com/firtoz/tab-canopy) - an experimental browser extension for hierarchical tab management and local-first tab state.
- [GPT-Shell](https://github.com/firtoz/GPT-Shell) - an open-source Discord AI companion with ChatGPT-style conversations and image generation, now evolved into Erin.
- [react-three-renderer](https://github.com/firtoz/react-three-renderer) - an early React renderer for three.js, now archived but still part of my WebGL history.
- [Unity3D Texture Atlas Slicer](https://github.com/firtoz/Unity3D-TextureAtlasSlicer) - a Unity editor tool for importing XML texture atlases and slicing sprites quickly.

I like making tools that help people build, learn, play, and express ideas faster.
